# Export du work item 417829 (User Story)

Titre : Créer une nouvelle demande
Type : User Story
Commentaires : 4 (non exportés)

## Description

### User Story

- En tant qu'utilisateur disposant du rôle Admin ou SuperAdmin,
- je veux créer une nouvelle demande depuis la liste des demandes
- afin d'initier un processus de gestion de mandat de Commissariat aux Comptes.

### Flow utilisateur

L'utilisateur habilité peut créer une demande directement depuis la liste des demandes sans quitter l'écran courant. Le formulaire s'affiche dans un panneau latéral et s'adapte en fonction de la nature du mandat sélectionnée.

#### 1. Accès à la création

- L'utilisateur accède à l'écran "Liste des demandes".
- Le bouton "Nouvelle demande" est visible uniquement pour les rôles :
  - Admin
  - SuperAdmin
- L'utilisateur clique sur "Nouvelle demande".

#### 2. Ouverture du side panel

- Un panneau latéral s'ouvre sur la droite de l'écran.
- Le formulaire de création d'une demande est affiché.
- Le reste de l'écran demeure visible en arrière-plan.

#### 3. Sélection de la nature du mandat

L'utilisateur sélectionne une valeur dans le champ Nature du mandat.
Deux parcours sont possibles.

Parcours 1 : Renouvellement

Lorsque l'utilisateur sélectionne Renouvellement, le formulaire affiche :

- Entité ID (données héritées d'InfoCAC, pas de possibilité pour l'utilisateur de saisir librement un code)
- N° Requête BSC (libre)
- Affectée à (Nom par défaut du compte utilisateur connecté, saisie possible avec nom prénom connu des collaborateurs KPMG)
- Millésime (ouverture par défaut sur l'année fiscale en cours, drop down -20 ans et +10ans)
- Tous les champs sont obligatoires.

Parcours 2 : Nouveau mandat

Lorsque l'utilisateur sélectionne Nouveau, le formulaire affiche des champs complémentaires :

- Entité ID (données héritées d'InfoCAC ou du réferentiel, pas de possibilité pour l'utilisateur de saisir librement un code)
  - si l'utilisateur valide la création avec une entité ID alors surlignage en rouge du champs, titre du champs en rouge et message d'erreur sous le champs disant "entité ID inconnue"
- Reprise (Oui, non)
- N° Requête BSC (libre)
- Affectée à (Nom par défaut du compte utilisateur connecté, saisie possible avec nom prénom connu des collaborateurs KPMG)
- Millésime (ouverture par défaut sur l'année fiscale en cours) => comportement sur les dates sur cette US https://dev.azure.com/kpmgfr/InfoCAC/_workitems/edit/424139
- Tous les champs sont obligatoires.

#### 4. Validation

L'utilisateur clique sur "Valider la création".
Le système vérifie :

- les champs obligatoires ;
- les règles métier liées à la nature du mandat qui va influer sur le type de formulaire ;
- la présence des documents obligatoires ;
- une création de demande possible avec une entité ID qui n'a pas encore de statut ou bien un statut validé (erreur si une entité ID a déjà une demande en statut : en cours, retard ou révision) ;
- un message de confirmation ou d'erreur apparaît (cf maquettes).

#### 5. Création de la demande

Si les contrôles sont conformes :

- la demande est créée ;
- redirection vers la page du formulaire.
