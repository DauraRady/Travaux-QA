## Description

### User Story

En tant qu'utilisateur habilité à créer ou modifier un mandat, je veux renseigner un numéro d'engagement de manière facultative dans la section « Description du mandat », afin d'associer l'engagement concerné au mandat tout en empêchan[t … fin de phrase non lue].

### Flow utilisateur

L'objectif est de permettre l'association facultative de plusieurs engagements à un mandat, avec contrôle d'unicité avant validation.

1. L'utilisateur accède à la section « Description du mandat ».
2. Le champ « N° engagement » est disponible mais est facultatif.
3. L'utilisateur peut :
   - ne renseigner aucun engagement ;
   - renseigner un numéro d'engagement.
4. Pour le numéro renseigné, le système contrôle si le numéro est déjà associé à un engagement validé.
5. Si aucun conflit n'est détecté, l'utilisateur peut poursuivre le parcours.
6. Si un numéro est déjà validé, le système bloque son utilisation et affiche un message explicite permettant d'identifier le numéro concerné.

Messages d'erreur :

- Message dans le toaster : « Un engagement avec ce numéro existe déjà »
- Message sous le champ : Engagement erroné
- Champ surligné en rouge
