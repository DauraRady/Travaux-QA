## Description

### User Story

En tant que collaborateur habilité à compléter une demande, je veux que chaque valeur saisie dans la section Description du mandat soit automatiquement sauvegardée afin de ne pas perdre mon travail et de pouvoir reprendre ma saisie ultérieurement.

### Flow utilisateur

Cette fonctionnalité permet à l'utilisateur de renseigner la section Description du mandat sans avoir à effectuer d'action explicite de sauvegarde.
Chaque modification est enregistrée automatiquement afin de garantir la conservation des informations saisies même si la demande reste incomplète.

Étape 0. L'utilisateur accède à une demande en cours de création ou de modification.

Étape 1. L'utilisateur renseigne ou modifie un champ de la section Description du mandat. Exemples : Pays ; Type de mandat ; Catégorie du mandat ; Taxonomie ; Catégorie d'entité ; AGP ; Type d'EIP ; Marchés de cotation.

Étape 2. L'utilisateur quitte le champ.

Étape 3. Le système déclenche automatiquement la sauvegarde de la valeur.

Étape 4. Pendant l'enregistrement, le système affiche un indicateur de sauvegarde en cours.

Étape 5. Lorsque l'enregistrement est terminé : un indicateur de succès est affiché ; la dernière valeur est enregistrée en base.

Étape 6. Si une erreur technique survient : la valeur reste visible à l'écran ; l'utilisateur est informé que la valeur n'est pas sauvegardée ; une action de nouvelle tentative est proposée.

Étape 7. L'utilisateur peut continuer à compléter d'autres champs même si une sauvegarde est en échec.

Étape 8. Lors de la réouverture de la demande, les dernières données sauvegardées sont restaurées.

### Périmètre

Cette US couvre la sauvegarde automatique des champs de la section : Description du mandat.
Elle ne couvre pas : la validation de la demande ; les contrôles de complétude ; les contrôles métier bloquants.

### Règles de gestion

RG-AS-01 : Toute modification d'une valeur déclenche une sauvegarde automatique lors de la sortie du champ.
RG-AS-02 : Le système affiche un état de sauvegarde en cours pendant l'enregistrement.
RG-AS-03 : Le système affiche un état de succès lorsque l'enregistrement est terminé avec succès.
RG-AS-04 : Une erreur de complétude métier ne bloque pas la sauvegarde d'une valeur valide.
RG-AS-05 : Une demande peut être enregistrée même si l'ensemble des champs obligatoires n'est pas encore renseigné.
RG-AS-06 : Lorsque la sauvegarde échoue : la valeur reste affichée ; le système indique que la donnée n'a pas été sauvegardée ; l'utilisateur peut relancer la sauvegarde.
RG-AS-07 : Une erreur de sauvegarde sur un champ ne bloque pas la saisie ou la sauvegarde d'autres champs.
RG-AS-08 : Les dernières valeurs sauvegardées sont restaurées lors de la réouverture de la demande.
RG-AS-09 : Une section ne peut être considérée comme Remplie sur la base d'une donnée qui n'a pas été correctement enregistrée.
RG-AS-10 : Les états de sauvegarde sont indépendants des règles de validation métier. Une donnée peut être : sauvegardée ; mais non valide fonctionnellement.
