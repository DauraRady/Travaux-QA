## Description

### User Story

En tant que collaborateur habilité à compléter une demande, je veux que les sections du formulaire soient automatiquement adaptées au Pays et au Type de mandat sélectionnés afin de ne renseigner que les informations applicables à ma demande.

### Flow utilisateur

Cette fonctionnalité permet au système d'afficher uniquement les sections pertinentes du formulaire selon le pays et le type de mandat sélectionnés.
L'objectif est d'éviter la saisie d'informations inutiles, de simplifier le parcours utilisateur et d'assurer la conformité des informations demandées selon le contexte réglementaire applicable.

Lien Figma (maquette, non exportée)

Étape 0. L'utilisateur a renseigné : 1. Pays ; 2. Type de mandat.

Étape 1. L'utilisateur sélectionne ou modifie le champ Pays et/ou Type de mandat. Valeurs possibles du Type de mandat :
1. Certification des comptes ;
2. Durabilité ;
3. Certification des comptes & Durabilité.

Étape 2. Le système détermine les sections applicables en fonction : 1. du Pays ; 2. du Type de mandat.

Étape 3. Le système affiche les sections applicables.

Étape 4. Le système masque les sections non applicables.

Étape 5. Lorsque des données existent déjà dans une section devenue non applicable :
1. la section est masquée ;
2. les données sont conservées ;
3. les données ne participent plus à la complétude ;
4. les données ne participent plus à la validation.

Étape 6. Si la section redevient applicable dans le cadre de la même demande :
1. la section est réaffichée ;
2. les données précédemment sauvegardées sont restaurées.

Étape 7. Le système recalcule :
1. la complétude des sections ;
2. les contrôles applicables ;
3. l'état global de la demande.

### Règles de gestion

RG-SEC-01 : Cas général France. Pour les demandes dont le Pays = France, les sections affichées dépendent du Type de mandat.

| Type de mandat | Sections affichées | Sections masquées |
|---|---|---|
| Certification des comptes | Informations mandat Certification ; Informations de l'entité ; Référentiel et Normes | Informations mandat Durabilité ; Audit contractuel |
| Durabilité | Informations mandat Durabilité ; Informations de l'entité ; Référentiel et Normes | Informations mandat Certification ; Audit contractuel |
| Certification des comptes & Durabilité | Informations mandat Certification ; Informations mandat Durabilité ; Informations de l'entité ; Référentiel et Normes | Audit contractuel |

RG-SEC-02 : Cas des pays hors France. Lorsque le Pays sélectionné est différent de France, les sections Durabilité et Référentiel et Normes ne sont jamais affichées, quel que soit le Type de mandat sélectionné.
Les seules sections pouvant être affichées sont : 1. Informations mandat Certification ; 2. Informations de l'entité.
Conséquences :
- la section Informations mandat Durabilité est systématiquement masquée ;
- la section Référentiel et Normes est systématiquement masquée ;
- les données éventuellement saisies dans ces sections sont conservées mais ne participent plus à la complétude ni à la validation.

RG-SEC-03 : Lorsqu'une section devient non applicable : 1. la section est masquée ; 2. ses champs ne participent plus à la complétude ; 3. ses champs ne participent plus à la validation.

RG-SEC-04 : Lorsqu'une section devient non applicable : 1. les données déjà enregistrées ne sont pas supprimées automatiquement.

RG-SEC-05 : Lorsqu'une section redevient applicable dans la même demande : 1. les données précédemment sauvegardées sont réaffichées.
